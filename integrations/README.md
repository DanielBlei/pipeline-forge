# Pipeline Forge Integrations

Here is a place to facilitate, document, and test integrations to make them discoverable and easy to test with Pipeline Forge.

## Current Integrations

### Jenkins

The Jenkins integration evaluates the use of Pipeline Forge with Jenkins CI/CD pipelines. Aiming to explore more complex CI/CD pipelines and how they can be integrated with Pipeline Forge.

- **Jenkins Pipelines**: `integrations/jenkins/ci/`
- **Infrastructure**: The Jenkins infrastructure that runs these integration experiments is maintained in a separate repository: [pipeline-forge-jenkins-k8s](https://github.com/DanielBlei/pipeline-forge-jenkins-k8s)
